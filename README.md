# Avocado Price Prediction | Machine Learning Portfolio

Machine-learning study of **conventional and organic avocado prices**, focused on San Francisco, using historical weekly price, volume, and seasonal features.

## Methods
- Exploratory data analysis (EDA), distributions, correlations and volume relationships
- Linear Regression, KNN, Support Vector Regression, Random Forest
- **Neural Network:** scikit-learn MLP with architecture, activation and regularization search
- **Voting Regressor:** equal-weight ensemble of the five models
- Chronological train/validation/test evaluation and MAE, RMSE, R² comparisons

## Repository
- `notebooks/01_exploratory_data_analysis.ipynb` — original EDA
- `notebooks/02_conventional_price_prediction.ipynb` — original conventional analysis
- `notebooks/03_organic_price_prediction.ipynb` — original organic analysis
- `notebooks/04_svr_experiments.ipynb` — original SVR study (requires its separate preprocessed CSV inputs)
- `notebooks/05_neural_network_voting.ipynb` — additional executable MLP and voting analysis
- `src/compare_models.py` — reproducible comparison CLI
- `results/` — generated predictions, model scores, and figures

## Dataset
Provide (https://www.kaggle.com/datasets/neuromusic/avocado-prices/) `data/avocado-updated-2020.csv` with columns `date`, `type`, `geography`, `average_price`, and `total_volume`. **The dataset is not included**. The original notebooks may require additional data files (`preprocessed_x_train.csv`, etc.). Ensure you have permission to redistribute data before publishing.

## Run
```bash
python -m pip install -r requirements.txt
python src/compare_models.py --data data/avocado-updated-2020.csv
jupyter lab
```

The script selects San Francisco, trains on observations before 2020, tunes the MLP using the latest available training year, and evaluates once on 2020. The same split is used for both avocado types. Weekly features use only past price/volume values; this is a **one-week-ahead prediction study**, not a validated recursive 2021 forecast.

## Reproducibility notes
- The four source notebooks are preserved as supplied, including their existing outputs and exploratory choices; they have not been independently executed here.
- The new workflow avoids random shuffling and never uses the 2020 holdout for tuning.
- Weekly missing observations are forward-filled, which assumes the most recent known observation is available; inspect missing-week patterns before interpreting results.
- Equal-weight voting is a baseline ensemble, not a guarantee of improved performance.
- Reported model rankings must be generated by running against the dataset. No test scores are fabricated.

## Future improvements
Rolling-origin backtesting, tuning all ensemble components within time-series CV, region-level generalization, and uncertainty intervals.
